## About The Project

**The Hall of Fame** คือ ชื่อโปรเจ็ค**เกมการเรียนรู้ออนไลน์แบบ Multiplayer** รายวิชาประวัติศาสตร์สากลและสังคมศึกษา สำหรับนักเรียนระดับชั้น**มัธยมศึกษาปีที่ 3** ในหน่วยการเรียนรู้ **"สงครามเย็นและองค์กรความร่วมมือของโลกในคริสต์ศตวรรษที่ 20"**

ระบบจำลองบทบาทให้นักเรียนเป็น **"ทีมภัณฑารักษ์พิพิธภัณฑ์"** ที่ต้องร่วมมือกันกอบกู้ห้องจัดแสดงนิทรรศการที่ถูกโจรกรรม ผ่านการสืบเสาะข้อมูลประวัติศาสตร์ วิเคราะห์แยกแยะหลักฐานจริง/เท็จออนไลน์ บริหารงบประมาณดิจิทัล และจัดแสดงของโบราณวัตถุลงบนแท่นวางรูปปั้น โดยมีครูผู้สอนควบคุมจังหวะการเล่นผ่าน **Teacher  Dashboard**

## Game Flow

การดำเนินเกมบนระบบออนไลน์แบ่งออกเป็น **4 Phases** ดังนี้

```
+-----------------------------------------------------------------------------------------------------------------------+
|                                              ONLINE GAMEPLAY TIMELINE                                                 |
+-----------------------------------------------------------------------------------------------------------------------+
|  [Phase 1 : LOBBY]   ➔   [Phase 2 : BRIEFING]   ➔   [Phase 3 : SHOPPING & EXHIBIT]   ➔   [Phase 4 : LEADERBOARD]  |
|  - สแกน QR Code เข้าห้อง   - อ่านแฟ้มลับภัณฑารักษ์อาวุโส   - งบประมาณดิจิทัล 10,000 บาท        - ชมห้องจัดแสดง 3D เสมือนจริง  |
|  - ตั้งชื่อทีม 8 กลุ่ม        - สืบเสาะเหตุการณ์ประจำห้อง     - ซื้อรูปปั้น + หลักฐาน + เรื่องราว        - ตรวจเฉลย & สรุปคะแนนระบบ     |
|  - รวมสมาชิก 5–6 คน/ทีม   - วิเคราะห์เบาะแสคำใบ้         - สแกน QR ตรวจ Fact vs Fault       - ครูให้คะแนน Rubric ออนไลน์    |
+-----------------------------------------------------------------------------------------------------------------------+
```

### 1️⃣ Phase 1 : Lobby (รวมพลภัณฑารักษ์)
* นักเรียนสแกน QR Code เพื่อเข้าสู่ห้องเกม
* แบ่งกลุ่มออกเป็น **8 ทีม (ทีมละ 5–6 คน)** ตั้งชื่อทีมและระบุชื่อสมาชิกในระบบ
* ครูมอนิเตอร์รายชื่อทีมที่ออนไลน์พร้อมกันจากหน้าจอครู (`/teacher`) และกดสั่งเริ่มเกม

---

### 2️⃣ Phase 2 : Briefing (อ่านบรีฟ)
* แต่ละกลุ่มจะได้รับมอบหมายห้องนิทรรศการ 1 ใน 8 ห้อง อ่านไฟล์ **"บันทึกของภัณฑารักษ์อาวุโส"**
* นักเรียนร่วมกันวิเคราะห์เนื้อเรื่อง บริบท และคำใบ้เพื่อหาข้อสรุปว่าห้องจัดแสดงของตนคือเหตุการณ์ประวัติศาสตร์ใด
* ศึกษาเนื้อหาเพื่อเตรียมวางแผนจัดซื้อของจัดแสดงในพิพิธภัณฑ์ตามโจทย์ที่ได้รับ

---

### 3️⃣ Phase 3 : Shopping & Investigation
* **งบประมาณ:** เริ่มต้น 10,000 ฿
* **Marketplace:** นักเรียนเข้าไปเลือกซื้อ Item เพื่อนำมาจัดแสดงให้ครบและถูกต้อง:
  - **Statues:** ชิ้นละ **1,000 บาท** 
  - **Evidence File:** ชิ้นละ **500 บาท** 
  - **Story Placards:** ชิ้นละ **500 บาท**
* **ระบบตรวจสอบหลักฐาน:**
  - นักเรียนสามารถคลิกส่องการ์ดหรือสแกน **QR Code** บนหน้าจอเพื่อเชื่อมต่อไปยังคลังเอกสารและแหล่งเรียนรู้จริง (UN, WTO, Britannica, MFA, Silpa-Mag, YouTube)
  - **วิเคราะห์ข้อเท็จจริง:**
    -  **หลักฐานแท้ (Authentic Evidence)** ได้รับ **+100 คะแนน/ชิ้น**
    -  **หลักฐานเท็จ (Counterfeit)** หากหลงเชื่อและนำมาจัดแสดงจะถูกหัก **-200 คะแนน/ชิ้น**
* **การบริหารเงินและเวลา:** ยิ่งบริหารเงินเหลือและส่งห้องจัดแสดงเร็ว จะ + **Point Budget Bonus** และ **Speed Bonus**

---

### 4️⃣ Phase 4 : Leaderboard 
* **Exhibition:** นักเรียนต้องจัดห้องนิทรรศกาตามแต่ละทีม ด้วยการวางแท่นวางรูปปั้น ป้ายเรื่องราว และแฟ้มเอกสารที่ตรงกับโจทย์ที่ได้รับ
* **ระบบคิดคะแนนอัตโนมัติ:**
  - คะแนนรูปปั้นถูกต้อง 
  - คะแนนหลักฐานแท้ 
  - หักคะแนนหลักฐานเท็จ 
  - คะแนนโบนัสงบประมาณ + โบนัสความเร็ว
* **การประเมินคะแนน:**
  - ครูสามารถคลิกให้คะแนนผ่านระบบได้แบบเรียลไทม์ (4 ด้าน ด้านละ 5 คะแนน)
* **Digital Walk Gallery:** นักเรียนสามารถเปิดชมนิทรรศการของเพื่อนกลุ่มอื่นในห้องเรียนได้ทันที

## App Routes

### 1. 🧑‍🎓 หน้าจอผู้เล่น / นักเรียน
* **Lobby Screen:** สแกนเข้าร่วมห้อง ระบุ USERNAME
* **Briefing:** อ่านบันทึกเรื่องเล่าภัณฑารักษ์
* **Marketplace:** ร้านค้าจัดซื้อรูปปั้น แฟ้มหลักฐาน และป้ายคำอธิบาย
* **Museum View:** แท่นจัดแสดงงานนิทรรศการ
* **Leaderboard & Summary:** แสดงตารางคะแนน สรุปอันดับ ชมนิทรรศการทีมอื่น

### 2. 👩‍🏫 หน้าจอครูผู้สอน (`/teacher`)
* **Live Phase Controller:** สั่งสลับขั้นตอนของเกมแบบ Real-time (`LOBBY` ➔ `BRIEFING` ➔ `SHOPPING` ➔ `LEADERBOARD`)
* **Classroom Timer:** นาฬิกาจับเวลานับถอยหลังพร้อมปุ่ม Pause / Resume / Reset
* **Live Team Inventory Monitor:** ตรวจสอบกระเป๋าไอเทม งบประมาณคงเหลือ และสถานะการส่งงานของนักเรียนทั้ง 8 กลุ่มแบบ Real Time
* **Teacher Rubric Evaluator (0–20 คะแนน):**
  - ความถูกต้องของการคัดกรองหลักฐาน (0–5 คะแนน)
  - การวิเคราะห์และเชื่อมโยงเหตุการณ์ (0–5 คะแนน)
  - การอธิบายระหว่างการนำเสนอ (0–5 คะแนน)
  - ทักษะการนำเสนอในบทบาทภัณฑารักษ์ (0–5 คะแนน)

### 3. 🏛️ หน้าคลังพิพิธภัณฑ์ (`/archive`)
* แคตตาล็อกแสดงสื่อการเรียนรู้ทั้งหมดในระบบ:
  - **32 รูปปั้นบุคคลสำคัญ**
  - **40 แฟ้มเอกสารหลักฐาน** พร้อม Barcode และแหล่งที่มา
  - **26 ป้ายคำอธิบายเรื่องราวประวัติศาสตร์** ระดับ HD (Museum Placards)

## 🛠️ Tech Stack & Architecture

```
[ Frontend: Next.js 14 App Router + React 18 + Tailwind CSS ]
                              │
                              ▼
[ Game State Engine: Server-side In-Memory State Sync (`src/lib/gameState.ts`) ]
                              │
                              ▼
[ Deployment: Railway Cloud Container Platform ]
```

| หมวดหมู่ | เทคโนโลยีที่เลือกใช้ | รายละเอียดการทำงาน |
| :--- | :--- | :--- |
| **Framework** | **Next.js 14.2 (App Router)** | รองรับทั้ง Server Component และ Real-time Client State |
| **Language** | **TypeScript 5.5** | Type-safe ตรวจสอบ Data Integrity ของห้องและไอเทม |
| **Styling & UI** | **Tailwind CSS 3.4** | ออกแบบ UI โทน Dark Luxury Museum ตัดสีทอง Champagne Gold |
| **Icons & Animation**| **Lucide React + Framer Motion** | ไอคอนและเอฟเฟกต์การเคลื่อนไหว นุ่มนวล สมจริง |
| **Typography** | **SF Pro TH + Noto Sans Thai** | ฟอนต์คมชัด อ่านง่าย สไตล์มาตรฐาน Apple Interface |
| **Deployment** | **Railway Cloud** | ระบบ Cloud Container รันโปรเจกต์ได้เสถียรและรวดเร็ว |

## 🚀 วิธีการติดตั้งและรันในเครื่อง (Local Setup)

### 1. Clone โปรเจกต์ & ติดตั้ง Dependencies
```bash
git clone https://github.com/Eterhart/HOF.git
cd HOF
npm install
```

### 2. รันเซิร์ฟเวอร์สำหรับทดสอบ (Development Mode)
```bash
npm run dev
```
เปิดบราวเซอร์ไปที่:
- 🧑‍🎓 **หน้านักเรียน:** `http://localhost:3000`
- 👩‍🏫 **หน้าแผงควบคุมครู:** `http://localhost:3000/teacher`
- 🏛️ **หน้าคลังพิพิธภัณฑ์:** `http://localhost:3000/archive`

### 3. คำสั่ง Build สำหรับ Production
```bash
npm run build
npm run start
```

## 🎓 คุณค่าและประโยชน์ทางการศึกษา (Educational Outcomes)

1. **การคิดวิเคราะห์ด้วยวิธีการทางประวัติศาสตร์:** ฝึกสืบค้น รวบรวม และประเมินคุณค่าของหลักฐานทางประวัติศาสตร์ผ่านระบบดิจิทัล
2. **การรู้เท่าทันสารสนเทศและสื่อ:** ฝึกสังเกตและแยกแยะข้อมูลจริง (Fact) ออกจากข้อมูลลวง (Misinformation)
3. **การทำงานเป็นทีมและการบริหารทรัพยากร:** ฝึกวางแผนกลยุทธ์ การบริหารงบประมาณ และการตัดสินใจร่วมกันในทีม
